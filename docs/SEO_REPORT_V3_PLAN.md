# SEO Report V3 Plan (Active Product Direction)

## Purpose

Reports answer:

> Can search realistically help this business get discovered, trusted and contacted, and what should the business improve first?

Customer journey: Business → Customer → Search / AI-powered discovery → Website → Understanding → Trust → Enquiry → Business opportunity.

Technical SEO supports that journey; it is not the main story.

## Evidence

Use the structured Website Evidence Package (`OBSERVED — WEBSITE`, `OBSERVED — EXTERNAL`, `INFERRED`, `NOT VERIFIED`).

Hard rule: do not claim something “does not exist” merely because it was absent from analysed pages. Prefer “not observed in the pages reviewed”.

External data (DataForSEO, GSC, GA, CRM, SERP scraping, etc.) is **deferred**. `externalEvidence` stays available but marked not collected.

## Snapshot V3 (10 keys)

BUSINESS_CUSTOMER_UNDERSTANDING, SEARCH_OPPORTUNITY, WEBSITE_OFFER_CLARITY, TRUST_REPUTATION, TRADITIONAL_SEARCH_READINESS, AI_DISCOVERY_READINESS, CUSTOMER_CONTENT_OPPORTUNITIES, ENQUIRY_READINESS, TOP_PRIORITY_ACTIONS, LIMITS_NEXT_STEP.

Length ~800–1,100 words. 3–5 priorities. No numeric scores.

## Detailed V3 (16 keys)

EXECUTIVE_BUSINESS_ASSESSMENT through EVIDENCE_LIMITATIONS (see `types/reportV3.ts`).

Length ~1,800–2,600 words. Prioritise with Business Impact / Confidence / Effort / Timing. Roadmap: FOUNDATION / GROWTH / MONITOR & IMPROVE.

## Active system

V3 is the **default active** generation path. V2 remains only for reading historical archives. Old V2 DB prompts must not override V3 hardcoded prompts unless they contain required V3 section markers.
